# Reel: "Google is sending me users for free"

Gloss version of the reel. Screen-recording POV, voice-over. About 45 seconds.
Every screen named here is real and in this repo, so nothing has to be mocked.

**0 to 3s** (screen: Google results for "what is my skin type quiz", scroll past Healthline, Sephora, a Reddit thread)

VO: People google the exact things my skin app answers, and it was nowhere in the results. So I built pages that answer them.

**3 to 10s** (screen: glossaiskin.github.io/tools/skin-type-quiz/, answer a few questions, hit the result)

VO: Every question Gloss can answer gets its own page on my site. Someone searches "what is my skin type", they land on a quiz that actually works, they get their answer, and the page points them at the app for the real scores.

**10 to 20s** (screen: Google Ads, Keyword Planner, paste the list from seo/keywords.md, sort by volume)

VO: How do you know which questions to build? Google tells you. Inside Google Ads there is a tool called Keyword Planner. Paste in phrases, it gives you every related search with monthly volume, filterable by country. You do not have to run a single ad to use it.

**20 to 30s** (screen: Claude Code session, the prompt visible)

VO: So I had Claude write every way someone might search for what Gloss does. Dropped them all into Keyword Planner. Sorted by volume.

**30 to 40s** (screen: scroll through tools/ folder in GitHub, then flick through three of the live pages: sunscreen calculator, ingredient checker, purging quiz)

VO: Then for the top results I had it build a page for each one. Nine pages. A skin type quiz, a sunscreen calculator, a "can I mix these ingredients" checker. Each one solves the problem and links to the app.

**40 to 45s** (screen: Search Console, Performance tab, whatever it shows)

VO: This is week one so I have no ranking numbers yet. I'll post them either way.
